# F7 逆さの水面

- 概念: 水盤に映る彫刻の反射が、本物とは違う形をしている。
- 実装: 高さ 1.05 m の石の水盤。水面は半透明(opacity 0.42)で環境マップを映す金属質の板。中央の島(薄い円盤と細い柱)の上に立方体を積んだ彫刻、円盤の下に球を積んだ逆さの彫刻を吊るす。鏡像の位置に置くので反射として読める。
- 光: 上からのスポットと、水中の弱い点光源。
- 種明かし: 水面を透明にし(`MaterialSwap`)、水中の光を強くする(`LightChange`)。
- 推奨視点: 正面 2.4 m、ピッチ -0.34。配置は Fable の間の南西(-6, -27.5)。
