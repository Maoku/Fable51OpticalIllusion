# F2 傾きの間

- 概念: 床も壁も 12° 傾いた小部屋。カメラは水平を保つので、中に入ると球が坂を「登り」、鉛直な人形と下げ振りが傾いて見える。
- 実装: 部屋(4 × 4 × 2.8 m)を z 軸回りに 12° 回して置く。入口は傾きの軸上(高低差 0)にあり、入口前 0.9 m の帯で床の高さを 0 へ繋ぐ(`tiltedFloorHeight`)。`groundPatch` で傾いた床の上を歩ける。
- 球: 部屋の床に対して 6° 上る軌道は、世界では 6° の下り坂。球は世界の下り方向へ転がるので、部屋の中では登って見える。5 秒で転がり、1 秒止まって消え、戻る。
- 人形と下げ振り: 部屋の回転を打ち消して世界の鉛直に立てる。額は部屋に合わせて傾く。
- コリジョン: 傾いて覆いかぶさる側の壁は内側に寄せた AABB にする。
- 種明かし: 真の水平線(緑)と重力の矢印(橙)を表示し、壁を半透明にして外の水平な展示室を見せる。視点は固定しない(中に立ったまま)。
- 推奨視点: 入口から 0.9 m 中に入った位置。判定の中心は部屋の中心、半径 3.4 m。
