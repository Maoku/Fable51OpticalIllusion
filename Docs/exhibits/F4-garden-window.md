# F4 窓の外の庭

- 概念: 回廊の大窓から広大な水庭が見える。実際は窓の向こう 3.2 m に置いた 1/20 のジオラマ。
- 実装: 回廊の東壁にガラス入りの開口(幅 6.4、高さ 1.9、腰 0.85)。窓の外は古典の間と Fable の間に挟まれた中庭(ローカル x ±5.7、奥行き 8 m)で、奥と左右に空と遠山の書き割り、天井に空の面を張って囲う。
- 台: 天面 1.5 m(目の高さのすぐ下)。水面は金属質の反射板。木・石・東屋・灯籠は奥ほど小さく、霞の色に寄せる(疑似的な空気遠近)。小物は頂点色で 1 メッシュにまとめる(`MeshBatch`)。
- 縁の隠蔽: 手前に生垣と石の植栽壁を置き、台の縁と脚が窓から見えないようにする。
- 光: 範囲を限ったスポットと点光源(方向光は館内全体に及ぶので使わない)。
- 種明かし: 等身大の人型と 1 m の物差しを `Reveal` で現し、光を平坦な白にする。
- 推奨視点: 窓から 1.3 m(x = 0.7, z = -13)。
