# F3 色の部屋

- 概念: 均一な光で満たされた部屋。角も陰影も見えず奥行きが消える。2 枚の同じ灰色の板が別の色に見える。
- 実装: 内装(5 × 4.2 × 3.2 m)は無灯の `MeshBasicMaterial` 一色で塗る。陰影がないので稜線が見えない(角の丸めは不要)。色は 60 秒周期で暖色 → 寒色 → 暖色と淡く巡る。外側は館内と同じ漆喰の外殻。
- 板: 灰色 0x8c8c8c の板 2 枚。左を暖色(0xffb27a)、右を寒色(0x7fb0ff)のスポットで照らす。内装は無灯なので光の輪は見えない。
- 描画: high ティアの GTAO(スクリーンスペースの遮蔽)は、無灯のマテリアルでも深度と法線から入隅を暗くして稜線を描いてしまう。部屋の中にいる間だけ AO を切る(`PostProcess.suppressAO`)。一様な色面の中なので切り替わりは見えない。
- 種明かし: スポットを白に戻し(`LightChange`)、内装の色を白へ補間し、稜線を `WireframeReveal` で描き、板を中央に並べる(`TransformLerp`)。
- 推奨視点: 入口から 1.2 m 中。判定の中心は部屋の中心、半径 3.4 m。配置は Fable の間の南東(5.6, -24)。
