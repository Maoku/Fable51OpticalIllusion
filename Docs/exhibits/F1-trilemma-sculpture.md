# F1 三面の彫刻

- 概念: 一つの白い立体が、正面からは円、側面からは正方形、真上からは三角形に見える。
- 実装: 3 つのシルエットを 2D の符号付き距離関数で与え、押し出しの共通部分 `min(front, side, top)` を 3D の場として作る(`silhouetteSolid.ts`)。three.js の `MarchingCubes` で等値面を取り出す。解像度はティアで 40 / 56 / 72。
- 影: 3 面のパネルと床に、各シルエットを Canvas に焼き込んだデカールを貼る。実際の影は落とさない(位置とスケールを厳密に合わせるため)。
- 照明: 正面と上からの硬いスポット 2 灯。
- 種明かし: `CameraPath` で正面 → 横(正方形)→ 真上(三角形)へ飛び、3 つの形が一つの立体に重なることを見せる。視点固定。
- 推奨視点: 正面 2.8 m。配置は Fable の間の北西(-6.2, -33)。
- テスト: 場の 3 軸投影が入力シルエットと 1% 未満の不一致で一致すること。
