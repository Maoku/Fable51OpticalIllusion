# 修正項目

## C1:エイムズの部屋

ヒント表示時の斜め視点はサイズ比較がわかりにくい

## C7:くぼんだ顔

白い顔にライティングが強く当たっているため
わかりにくい

## F2:傾きの部屋

球が坂を登らず、下っているように見える

## F3:色の部屋

部屋のエッジが見えるため奥行きが消えてはいない

## F4:窓の外の庭

肝心の水庭が垣根があって全く見えない
フォグと被写界深度がかかっていない

## F6:終わらない階段

登っている最中に高さが狭まった部分があって、カメラがめり込む

## F7:逆さの水面

水面に見えない
もっとリアリスティックな水面にする必要があります
