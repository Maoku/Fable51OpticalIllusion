# F6 終わらない階段

- 概念: 回廊脇の塔の階段を登り続けると、いつの間にか出発した踊り場に戻っている。
- 実装: 正方形の core の周りに 4 本のフライト(各 8 段 × 0.175 m = 1.4 m)を反時計回りに巡らせ、1 周で 5.6 m 上がる。同じ形を 2 周分積む(`stairGeometry.ts`)。通路は core と外壁、傾いた天井で囲まれ、隣の周は見えない。天井の下面は、踊り場では床から、フライトでは段の勾配線から `headroom`(2.5 m)上に張る(`stairCeilingHeight`)。板は両端の点から向きと傾きを導くので、フライトごとに傾きの符号を取り違えることがない。
- 継ぎ目: 上の周の東側のフライト(A')の z ∈ [-1.0, -0.2] に入った瞬間、y を 5.6 m 下げる(`stairSeamShift`)。前後の見え方は下の周と同じなので分からない。上の周の踊り場 L0' の偽の戸口(袋小路)に入ったときも同様に下げ、本物の回廊へ出られるようにする。
- 足元: `groundPatch(x, z, y)` が現在の高さに近い周の段の高さを返す。
- 描画: 段・踊り場・天井・壁は同じマテリアルごとに `mergeGeometries` で結合。光源は周ごとに 1 灯(壁は光を遮らない)。
- 種明かし: `CameraPath` で屋根の上へ抜け、外壁と天井を半透明にし、継ぎ目の面(橙)を `Reveal` で示す。
- 推奨視点: 入口の踊り場 L0(-2.925, -10.725)から東のフライトを見上げる。
- テスト: 領域判定・周の選択・継ぎ目・天井の高さの単体テスト。E2E では継ぎ目をまたいだ後の y が 5.6 下がって x と z が変わらないこと、および組み上がったジオメトリを測って 4 本のフライトの頭上が揃っていること(各段の中央で 2.41 m、踊り場で 2.50 m)を確認。
